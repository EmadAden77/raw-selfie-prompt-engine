# محرك برومبت سيلفي واقعي
# Raw Selfie Prompt Engine

تطبيق ويب لإنشاء برومبتات إنجليزية دقيقة وموجهة إلى ChatGPT لتوليد صور سيلفي واقعية اعتمادًا على الصورة المرجعية للمستخدم واختياراته.

**التطبيق يولّد البرومبت فقط، ولا يولّد الصور.**

## فكرة المشروع

1. يرفع المستخدم صورته المرجعية الخاصة به.
2. يختار تفاصيل الصورة من واجهة عربية بالكامل.
3. يحوّل التطبيق الاختيارات إلى بيانات منظمة.
4. يعالج المحرك الاختيارات مع القواعد الثابتة.
5. يستخدم المحرك NVIDIA API لتوسيع التفاصيل الواقعية.
6. يتحقق من البرومبت النهائي.
7. يعرض برومبتًا إنجليزيًا جاهزًا للنسخ والاستخدام في ChatGPT.

عند فشل الاتصال بخدمة NVIDIA، يستخدم التطبيق مولّدًا محليًا قائمًا على القواعد دون تعطيل عملية إنشاء البرومبت.

## قواعد اللغة

- واجهة التطبيق عربية بالكامل.
- اتجاه الواجهة من اليمين إلى اليسار (RTL).
- جميع العناوين والأزرار والخيارات باللغة العربية.
- البرومبت النهائي باللغة الإنجليزية فقط.
- البرومبت النهائي موجّه إلى ChatGPT.
- لا تُضاف تعليمات عربية داخل البرومبت النهائي.

يبدأ كل برومبت بالنص التالي:

```text
ChatGPT, using the reference image I uploaded, generate an image of the exact same person...
```

## القواعد الثابتة

### 1. الهوية المرجعية

- الحفاظ على هوية الشخص من الصورة المرجعية.
- عدم تغيير ملامح الوجه أو لون البشرة أو شكل الجسم.
- عدم تطبيق التجميل أو تنعيم البشرة أو التبييض.
- الحفاظ على نسيج البشرة ومسامها الطبيعية.
- الحفاظ على كثافة الشعر وسماكته وخط نموه الأصلي.
- السماح بتغيير اتجاه التسريحة دون تغيير خصائص الشعر الأصلية.

### 2. السيارة الثابتة

**السيارة:** Range Rover Sport 2022

المواصفات الخارجية:

- اللون الأبيض اللؤلؤي.
- الباقة الرياضية.
- جنوط سوداء.
- شبك أمامي أسود.
- مصابيح LED أمامية.

المواصفات الداخلية:

- جلد بيج.
- مقاعد بيج.
- لوحة قيادة بيج.
- مقود بيج.
- ألواح أبواب بيج.
- سقف بانورامي.

لا يسمح المحرك بتغيير لون السيارة أو مواصفات الداخلية الثابتة.

### 3. السيلفي الخام

- تصوير بالكاميرا الأمامية للهاتف.
- منظور سيلفي حقيقي بيد الشخص نفسه.
- تشوه عدسة طفيف وطبيعي.
- ذراع وظلال ومنظور متوافق مع وضعية التصوير.
- تأطير عفوي وغير مثالي قليلًا.
- ضوضاء مستشعر الهاتف ونطاق ديناميكي واقعي.
- عدم استخدام إضاءة استوديو أو مظهر كاميرا احترافية.

### 4. منع المظهر الصناعي

المظهر المطلوب واقعي وطبيعي.

يمنع المحرك:

- Wax skin
- Plastic skin
- Porcelain skin
- Airbrushed skin
- Beauty filters
- CGI appearance
- 3D-rendered appearance
- Unrealistic HDR
- Artificially glossy surfaces

مع الحفاظ على ملمس البشرة الحقيقي وتجاعيد الملابس الطبيعية والغبار والانعكاسات الواقعية عند ملاءمتها للمشهد.

### 5. الأماكن والسيارة

- جميع المواقع بيئات سعودية يومية عامة.
- عدم استخدام أسماء معالم أو مولات أو أبراج مشهورة.
- السيارة متوقفة دائمًا.
- لا تتضمن البرومبتات قيادة السيارة أثناء الحركة.
- الخلفيات حية وليست فارغة.
- إضافة عناصر واقعية متوافقة مع الموقع والوقت والإضاءة.

### 6. الفيزياء والهندسة

- توافق وضعية الجسم مع زاوية الكاميرا.
- صحة مواضع اليدين والذراعين والمفاصل.
- اتساق اتجاه الضوء والظلال والانعكاسات.
- توافق الملابس مع الجاذبية والحركة.
- احترام المسافات والمنظور.
- تجنب التعارض بين الزاوية والوضعية والمكان.

## محرك إنشاء البرومبت

يتكون المحرك من طبقتين أساسيتين.

### Rule Builder

مسؤول عن:

- استقبال الاختيارات المنظمة.
- إضافة القواعد الثابتة.
- تثبيت الهوية المرجعية.
- تثبيت مواصفات السيارة.
- ضمان واقعية السيلفي.
- منع تعارضات الخيارات.
- إنشاء البرومبت الأساسي بالإنجليزية.

### Creative Expander

مسؤول عن:

- إضافة تفاصيل واقعية مناسبة للمشهد.
- تحسين وصف البيئة والخلفية.
- إضافة الانعكاسات والظلال الطبيعية.
- وصف حركة الشعر والملابس.
- إضافة تفاصيل العفوية والفوضى الواقعية.

لا يحق لطبقة التوسيع الإبداعي تغيير قواعد الهوية أو السيارة أو التصوير.

### Prompt Validator

يتحقق من:

- بداية البرومبت الإلزامية.
- اللغة الإنجليزية.
- وجود القواعد الثابتة.
- الحفاظ على مواصفات السيارة.
- عدم وصف السيارة أثناء القيادة.
- عدم وجود معالم مشهورة.
- الاتساق بين تفاصيل المشهد.

### Fallback Generator

إذا تعذّر استخدام NVIDIA API، يُنشئ البرومبت اعتمادًا على Rule Builder دون الحاجة إلى خدمة الذكاء الاصطناعي الخارجية.

## NVIDIA API

إعدادات الاتصال المعتمدة:

```text
Base URL:
https://integrate.api.nvidia.com/v1/chat/completions

Model:
deepseek-ai/deepseek-v4.1-flash
```

**حماية المفتاح:**

- يُحفظ مفتاح NVIDIA في ملف بيئة خاص بالـ Backend.
- لا يوضع المفتاح في واجهة المستخدم.
- لا يُرسل المفتاح إلى المتصفح.
- لا يُرفع المفتاح إلى GitHub.
- تُستخدم ملفات `.env.example` لتوضيح الإعدادات المطلوبة دون أسرار.

## تشغيل المشروع

المتطلبات المخططة:

- Node.js 20.19 أو أحدث، أو إصدار متوافق من Node.js 22 فأحدث.
- npm يدعم workspaces.

الواجهتان Frontend وBackend موجودتان بالفعل. بعد استنساخ المستودع، انسخ `backend/.env.example` إلى `backend/.env` محليًا، وضع `NVIDIA_API_KEY` فيه فقط إذا أردت استخدام NVIDIA. ترك المفتاح فارغًا يشغّل التوليد الاحتياطي. لا ترفع `.env` إلى GitHub.

شغّل الخادم والواجهة في نافذتي طرفية منفصلتين من جذر المشروع؛ الواجهة على `http://localhost:5173` والخادم على `http://localhost:3001`. أثناء التطوير يوجّه Vite طلبات `/api` إلى الخادم. في الإنتاج اضبط Reverse Proxy للمسار `/api` أو متغير `VITE_API_BASE_URL` عند بناء الواجهة، واضبط `CORS_ORIGINS` عند فصل النطاقين. اختبر `npm run typecheck` و`npm run build` و`npm test` قبل النشر.

## خصوصية الصورة المرجعية

- يستخدم التطبيق الصورة المرجعية الخاصة بالمستخدم فقط.
- الصورة المرجعية مخصصة للاستخدام مع البرومبت في ChatGPT.
- لا يحتاج محرك إنشاء النص إلى إرسال الصورة المرجعية إلى NVIDIA.
- لا تُضمّن بيانات الصورة في طلب توليد البرومبت النصي.
- لا تُخزن الصور المرجعية على الخادم ضمن التصميم الأساسي.
- المستخدم مسؤول عن رفع صورته إلى ChatGPT عند استخدام البرومبت.

## أمان التطبيق

- حفظ الأسرار في Backend فقط.
- التحقق من بيانات الطلبات.
- تحديد معدلات الطلبات.
- معالجة أخطاء الخدمات الخارجية.
- عدم كشف بيانات البيئة السرية.
- توفير توليد بديل عند فشل NVIDIA API.
