# NVIDIA v10: محرر نص فقط — لا مخطط مشاهد

المعمارية السابقة التي تطلب JSON من NVIDIA للتخطيط **متوقفة**. المصدر الوحيد لفيزياء الإضاءة والوقوف والكاميرا والملابس والهندسة هو Rule Builder مع الخيارات العربية التي اختارها المستخدم.

بعد أن يبني Rule Builder البرومبت الإنجليزي الكامل (195 سم / 88 كجم، هوية المرجع، Range Rover Sport 2022 متوقفة، المقصورة البيج بمقود أسود)، تستقبل NVIDIA النص ذاته وتعيده منقحًا فقط، بدرجة حرارة `0.25`.

`editor-validator.ts` يقارن كل الجمل الحاملة للحقائق بالنص الأصلي، ويقبل فقط التنقيح التحريري المتحقق منه. أي تغيير أو إضافة أو حذف غير مأمون يؤدي إلى إرجاع **البرومبت الأصلي حرفيًا**.

راجع الدليل الكامل: [محرك NVIDIA التحريري v10](nvidia-editor-only-v10.md).

**الاختبارات:** `npm run typecheck`، `npm run build`، `npm test`. النموذج لا يستقبل صورة الشخص ولا ينشئ صورة، ولا يملك سلطة إضافة أي حقيقة فوتوغرافية أو ميكانيكية.
