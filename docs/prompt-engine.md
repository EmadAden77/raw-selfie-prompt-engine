# معمارية محرك البرومبت v10

- **الواجهة (RTL عربية):** تمرر معرّفات الخيارات الثمانية وقيمة `variation` فقط؛ لا ترسل صورًا أو مفتاح NVIDIA.
- **Rule Builder:** يحدد هوية الشخص، 195 سم و88 كجم والبنية الرياضية الطبيعية، مواصفات Range Rover Sport 2022، خامات وميكانيكا المقصورة، وقوف السيارة وملمس الطريق، مصدر الضوء وحرارته واتجاه الظلال وهندسة كاميرا السيلفي.
- **برومبت Rule Builder:** `backend/src/engine/concise-prompt.ts` يجمع النص الإنجليزي النهائي مع البداية الإلزامية، بترتيب الهوية، الجسم، السيارة، المشهد، الملابس، الإضاءة ثم بقية التفاصيل.
- **NVIDIA (Editor only):** عند توفر مفتاح خادم صالح، تستقبل البرومبت المكتمل حرفيًا، وتحاول تنقيح الصياغة الإنجليزية بدرجة حرارة `0.25`. لا تستقبل صورة أو مخطط مشهد JSON ولا تضيف حقائق.
- **Editorial Validator:** `backend/src/engine/editor-validator.ts` يقارن كل الجمل بالمرجع؛ لا يقبل تغييرات في المحتوى الواقعي. الرد غير المطابق يُرفض.
- **Fallback Generator:** هو النص نفسه الصادر من Rule Builder، دون تنقيح. ويستخدم المتصفح محرك القواعد نفسه عند تعذر الخادم.

## هندسة المشهد

عندما يوجد رصيف مناسب ومسموح ضمن إطار السيلفي، تُصفّ السيارة موازية له بعجلات مستقيمة على بعد 20–30 سم من رصيف خرساني بيج/رمادي ارتفاعه 15 سم؛ الطرق الصحراوية لا يُختلق فيها رصيف، ومواقف السيارات تبقى ضمن خطوطها الفعلية. الإضاءة وKelvin والملابس ومقدار الجسم والسيارة الظاهر لا يحددها NVIDIA إطلاقًا.

## سلامة الصياغة

التحقق النصي الدقيق لا يستطيع ضمان تكافؤ جميع إعادة الصياغات الحرة؛ لذا يقبل فقط تحسينات شكلية مثبتة (علامات الترقيم، أدوات التعريف، الحروف الكبيرة والمسافات، وترتيب جمل متطابقة بالمعلومات). عند الشك تُعاد صياغة Rule Builder الأصلية دون حذف أي حقيقة.

تفاصيل أوسع: [NVIDIA Editor-Only v10](nvidia-editor-only-v10.md).
