# NVIDIA Intelligent Photorealism Engine

## ما تغيّر في المحرك

تمت ترقية التكامل من توليد فقرة إنجليزية مفتوحة إلى **خطة مشهد واحدة بصيغة JSON**، يُتحقق منها محليًا ثم تُركّب نتائجها مع النصوص الإلزامية المحمية. لم تُعد كتابة الواجهة ولم تُغيّر الخيارات الثمانية.

### خط سير التنفيذ

1. **Rule Builder** ينشئ النص الأساسي المحمي من الاختيارات، ويثبت هوية الشخص، 195 سم، 88 كجم، السيارة المتوقفة، المقصورة، والمصدر الضوئي واتجاه الظلال.
2. **Scene Planner** ينشئ خطة مرجعية حتمية تتضمن ثمانية أقسام: هندسة الكاميرا، وضعية الجسم، الضوء، الهوية، البيئة، القماش، الأجزاء المرئية من السيارة، وخصائص تصوير الهاتف. المخطط موجود في `backend/src/engine/scene-planner.ts` ويتحقق منه Zod.
3. **NVIDIA** تستقبل الاختيارات والنص الوصفي للخطة المرجعية فقط، **ولا تستقبل صورة الشخص**. تطلب الاستجابة JSON واحدًا بالأسماء والأنواع نفسها. لا يُسمح للنموذج بتعديل القواعد المحمية أو كتابة البرومبت النهائي.
4. **Consistency Critic** يراجع الخطة المقترحة ويستعيد الحقول المحمية عندما تختلف؛ لا يسمح إلا بتفاصيل واقعية محدودة في الخلفية والقماش والملمس والتعريض، ويستبعد الأوصاف المخالفة. JSON ناقص أو غير صالح يُرفض بدل محاولة تفسيره كنص حر.
5. **Realism Director** يختار وصف الكاميرا والقماش والإضاءة والبيئة الملائم للمشهد، ولا يكدّس جميع تأثيرات التصوير في كل مشهد.
6. **Prompt Assembler** يُبقي النص الأساسي حرفيًا، ويضيف وصف الواقعية المنتقى بنسبة عرض 9:16.
7. **Quality Evaluator** يعيد ست نتائج تشخيصية داخل الخادم: الهوية، الهندسة، الإضاءة، المواد، الكاميرا، والتناقضات. لا يقدم درجة زائفة ولا يدّعي فحص الصورة الناتجة.
8. **Fallback Generator** الأصلي يبقى فعالًا عند غياب المفتاح أو رفض NVIDIA أو مهلة الاتصال أو JSON غير صالح أو فشل التقييم. ويبقى مولّد المتصفح المحلي موجودًا إذا كان Backend غير متاح.

### إعداد NVIDIA

- النموذج الرئيسي الحالي: `deepseek-ai/deepseek-v4.1-flash`.
- درجة حرارة التخطيط الافتراضية: **0.3**، ويمكن اختبارها بالخادم عبر المتغير الاختياري `NVIDIA_PLAN_TEMPERATURE` ضمن المجال 0–1. لا توجد إضافة لحقول الواجهة أو أي مفتاح API داخل المستودع.
- يستخدم الطلب JSON عاديًا مع تحقق صارم عبر Zod؛ لا نفترض دعم النموذج لـJSON Schema مُقيَّد من واجهة NVIDIA دون إثبات ذلك.
- تتم محاولة نموذج NVIDIA السريع الاحتياطي **مرة واحدة فقط عند فشل اتصال أو مهلة أو عدم توفر الموديل**، وليس عند خطأ JSON أو مفتاح غير صالح.
- مهلات الاتصال وإدارة المفتاح ومسارات الاستضافة باقية ضمن الإعدادات الحالية.

### ما يُحظر على NVIDIA

لا تغيير لشخص الصورة المرجعية أو ملامحه وشعره وبشرته، ولا للطول **195 سم** أو الوزن **88 كجم** والبنية **Lean Athletic**، ولا للسيارة **Range Rover Sport 2022** البيضاء اللؤلؤية ومقصورتها البيج والخشب الداكن والكروم وPiano Black والمقود الأسود. السيارة متوقفة على أرض واقعية، والشخص هو الموضوع الرئيسي الوحيد، ولا تُفتح زاوية السيلفي لاستعراض عناصر خارج الكادر.

### الاختبارات والقيود

- `backend/tests/nvidia.test.ts`: محاكاة JSON صالح وغير صالح، المفتاح المرفوض، المهلة وإعادة المحاولة، تصحيح الحقول، ودرجة حرارة 0.3 و0.5، دون استهلاك NVIDIA فعليًا في الاختبار.
- `backend/tests/scene-intelligence-benchmark.test.ts`: ثمانية مشاهد ثابتة نهارية وليلية، داخل السيارة وخارجها، مع تغيّر الإضاءة والزاوية والوضعية والمقود، وفحص الجودة النصي.
- تبقى اختبارات جميع اختيارات الملابس والتعابير والشعر والزوايا والوضعيات والأماكن والإضاءة والوقوف ضمن الاختبارات السابقة.

**ملاحظة مهمة:** تقييم الجودة يتحقق من سلامة البيانات والبرومبت **نصيًا** فقط، ولا يُثبت واقعية الصورة النهائية أو يصنف قابليتها للاكتشاف. نجاح اختبار JSON وهمي لا يؤكد قبول نموذج NVIDIA الحقيقي؛ يتطلب ذلك اختبارًا باستخدام مفتاح مستخدم صالح دون كشفه.

### ملفات التنفيذ المرتبطة

| الملف | التعديل |
|---|---|
| `backend/src/engine/scene-planner.ts` | JSON Schema عبر Zod وخطة حتمية من ثمانية أقسام |
| `backend/src/engine/consistency-critic.ts` | مراجعة الحقول وإصلاح التعارضات محليًا |
| `backend/src/engine/realism-director.ts` | تفاصيل واقعية قليلة ومرتبطة بالمشهد |
| `backend/src/engine/quality-evaluator.ts` | ست نتائج تشخيصية مستقلة |
| `backend/src/prompts/nvidia-scene-plan-prompt.ts` | تعليمات JSON المحمية |
| `backend/src/services/nvidia.service.ts` | مسار طلب JSON، درجة الحرارة والتحقق والمهلة |
| `backend/src/services/prompt.service.ts` | ربط التخطيط والمراجعة والتقييم بـRule Builder وPrompt Assembler |
| `backend/tests/nvidia.test.ts` | اختبارات mocks للاتصال والحماية والردود |
| `backend/tests/scene-intelligence-benchmark.test.ts` | المشاهد المرجعية وتصحيح التعارض |

تُراجع نتائج البناء والاختبارات في GitHub Actions بعد كل تحديث على `main`.
