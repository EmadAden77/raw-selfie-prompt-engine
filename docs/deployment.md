# تشغيل ونشر محرك برومبت السيلفي

## ما الذي يُنشَر؟
التطبيق يولّد **برومبت باللغة الإنجليزية فقط**. الصورة المرجعية تُختار للمعاينة في المتصفح، ولا تُرفع إلى Backend أو NVIDIA؛ يستخدمها المستخدم لاحقًا في ChatGPT عند توليد الصورة. واجهة الخيارات عربية RTL.

- الواجهة المنشورة: https://emadaden77.github.io/raw-selfie-prompt-engine/
- خادم API: https://raw-selfie-nvidia-api-emadaden77s-projects.vercel.app
- GitHub Pages ينشر الواجهة بعد دمج تغييرات `main`. خادم Vercel مستقل ويلزم التأكد من نشر التحديث عليه أيضًا.

## سرية مفتاح NVIDIA — مسار v10
1. محليًا: انسخ `backend/.env.example` إلى `backend/.env` (ملف غير متتبع) وضع مفتاحك في `NVIDIA_API_KEY`.
2. على Vercel: أضف `NVIDIA_API_KEY` في **Project Settings → Environment Variables** إلى بيئة الخادم المطلوبة، بنوع Sensitive أو Encrypted. لا تشاركه في محادثة أو سجلات أو GitHub.
3. لا تُدخل المفتاح في الواجهة، ولا تستخدم `VITE_NVIDIA_API_KEY` أو متغيرًا يبدأ بـ `VITE_`. طلب المتصفح يحمل `selections` و`variation` فقط.
4. إذا لم يُضبط مفتاح صالح في الخادم، يُستخدم المولّد المحلي الآمن. عند تعذّر اتصال المتصفح بالخادم، تعمل النسخة المضمّنة في الواجهة دون إنترنت.
5. عند فتح واجهة v9 للمرة الأولى، تُمسح القيمة القديمة للمفتاح المخزنة في `localStorage` من الإصدارات السابقة. من الأفضل إبطال المفتاح القديم إذا استُخدم في جهاز مشترك أو موقع غير موثوق.

**تنبيه أمني:** الموقع المنشور عام. حيازة الخادم لمفتاح NVIDIA لا تجعل نقطة API العامة خاصة؛ قيود CORS وrate limiting الذاكرية ليست نظام مصادقة ولا حدًّا عالميًا للفوترة في بيئة serverless. لا تفعّل مفتاحًا مدفوعًا على API عام دون مصادقة قوية أو حماية منصة/بوابة API وحدّ استهلاك مركزي. يمكن ترك المفتاح غير مضبوط واستعمال المولد المحلي.

## التشغيل المحلي
من جذر المستودع:
```bash
npm install
npm run dev:backend
npm run dev:frontend
```

افتح `http://localhost:5173`. تتصل واجهة Vite بالخادم المحلي على `127.0.0.1:3001` عبر Proxy. الخادم يحمّل `backend/.env` إن وجد؛ عدم وجود المفتاح لا يمنع التوليد المحلي.

## فحوصات ما قبل الدمج
```bash
npm run typecheck
npm run build
npm test
```

يتحقق CI من بناء الواجهة والخادم، وقواعد الهوية والسيارة والمقصورة، وتوافق الكاميرا، وأن NVIDIA محرر فقط ويرجع fallback مطابقًا للمعلومات. لا تُثبت هذه الفحوصات تطابق الصورة الناتجة مع المرجع؛ فهذا يتطلب فحصًا بصريًا منفصلًا للصورة التي يولّدها ChatGPT.

## قواعد الإنتاج
- الصورة المرجعية هي مصدر الهوية؛ الطول 195 سم والوزن 88 كجم وبنية رياضية نحيفة.
- السيارة Range Rover Sport 2022 لؤلؤية بيضاء، جنوط وشبك أسودان، داخلية جلد بيج وطبلون بيج ومقود **جلد أسود**، وسقف بانورامي وشاشتان Touch Pro Duo بالأبعاد الأصلية. السيارة متوقفة.
- الصورة سيلفي خام بكاميرا الهاتف Xiaomi 15 Ultra. يُستخدم مسار الكاميرا الخلفية للانعكاس فقط، ومسار الحامل مع المؤقت فقط عندما تكون اليدان على الدركسون.
- لا معالم مشهورة، ولا توسيع للكادر لإظهار تفاصيل خارج زاوية السيلفي.
