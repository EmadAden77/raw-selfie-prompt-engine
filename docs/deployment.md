# تشغيل خاص فقط — بدون نشر عام

> **هذا التطبيق مخصص لك وحدك.** لا تنشره على Vercel أو Netlify أو GitHub Pages أو أي نطاق أو خادم متاح للجمهور. لا تضف زر نشر تلقائي. احتفظ بالمستودع **Private**، ولا تغيّر رؤية منافذ Codespaces إلى Public.

## GitHub Codespaces — تشغيل تلقائي خاص (دون تيرمكس أو أوامر)

جهز المشروع إعداد `.devcontainer/devcontainer.json` ليقوم Codespaces الجديد تلقائيًا بتثبيت الاعتماديات، وبدء Backend والواجهة الأمامية، وتوجيه المنفذ **5173**. لا يحتاج المستخدم إلى أوامر أو تنزيل ملفات أو توكن شخصي.

1. افتح [المستودع الخاص على GitHub](https://github.com/EmadAden77/raw-selfie-prompt-engine).
2. اضغط **Code → Codespaces → Create codespace on main**.
3. بعد انتهاء تجهيز Codespace، افتح **Ports** واضغط **Open in Browser** للمنفذ **5173**؛ قد تُفتح الواجهة تلقائيًا.
4. تحقق من أن خصوصية المنفذ **5173 = Private**. إن كان Public فاختر **Port Visibility → Private** فورًا. لا تنشر الرابط.
5. أدخل مفتاح NVIDIA في الخانة العلوية داخل التطبيق نفسه فقط إذا أردت الاتصال الفعلي؛ أدخله في واجهة المتصفح، **وليس في GitHub أو المحرر أو Terminal**. عند عدم وجود مفتاح تستخدم القواعد المحلية.
6. إن كان Codespace موجودًا قبل إضافة إعدادات المشروع، يلزم اختيار **Rebuild Container** من قائمة أوامر Codespaces لتطبيق إعدادات الحاوية الجديدة؛ لا يلزم تشغيل الأوامر يدويًا بعد إعادة البناء.

### حدود حماية المنافذ

- GitHub يجعل المنافذ المحوّلة **Private افتراضيًا**، لكنها إعدادات قابلة للتغيير من صاحب Codespace. `.devcontainer` يطلب فتح المنفذ 5173 فقط، ولا يستطيع قفل خيار المشاركة العامة من حساب فردي.
- Backend يستمع في Codespaces على `127.0.0.1:3001` فقط؛ تتواصل معه الواجهة عن طريق Vite Proxy عبر `/api`. لا يطلب المشروع تحويل المنفذ 3001.
- الرابط الخاص للمنفذ 5173 يتطلب تسجيل الدخول إلى GitHub؛ **ليس نشرًا عامًا**. احفظ الرابط لنفسك وأوقف Codespace بعد استخدامه.
- لا توجد أي طريقة تؤكد عمل مفتاحك الحقيقي لدى NVIDIA دون إدخاله في التطبيق وتشغيل الطلب من حسابك؛ اختبارات GitHub الآلية تستخدم محاكاة دون أسرار.
- ليس لدينا اتصال مباشر لإدارة جلسات Codespaces أو قراءة حالة منفذ حقيقي؛ إعدادات المشروع والاختبارات تثبت صلاحية التهيئة فقط.

مراجع GitHub: [إنشاء Codespace](https://docs.github.com/en/codespaces/developing-in-a-codespace/creating-a-codespace-for-a-repository) و[خصوصية المنافذ](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace).

## الخيار الآخر: تشغيل محلي على جهازك (localhost)

1. افتح نسخة المستودع على جهازك (بعد تنزيلها من مستودعك الخاص) وتأكد من توفر Node.js متوافق وnpm.
2. افتح طرفية في مجلد المشروع ونفّذ:

```bash
npm install
```

3. شغّل الخادم في نافذة طرفية أولى:

```bash
npm run dev:backend
```

4. شغّل الواجهة في نافذة طرفية ثانية:

```bash
npm run dev:frontend
```

5. افتح `http://localhost:5173` في المتصفح. سيتصل Vite بالخادم على `http://localhost:3001` عبر `/api/prompt`. لا تفتح منافذ الراوتر أو جدار الحماية للعامة، ولا تستخدم خدمات مشاركة أو أنفاق عامة.

هذه الخطوات تشغّل التطبيق محليًا فقط ما لم تغيّر إعدادات الشبكة أو مشاركة المنافذ بنفسك. ولأن خادم التطوير قد يستمع لكل واجهات الشبكة، تجنّب تشغيله على شبكات غير موثوقة ولا تكشف المنافذ إلى الأجهزة الأخرى.

## مفتاح NVIDIA الخاص بك

- لا تحتاج إلى إنشاء `backend/.env` أو كتابة المفتاح في أي ملف؛ هذه الطريقة القديمة لا تلزم لاستخدام الواجهة الحالية.
- داخل التطبيق افتح خانة **«مفتاح NVIDIA الخاص بي»** الموجودة أعلى الصفحة.
- الصق المفتاح الذي يبدأ بـ `nvapi-`. تحفظه الواجهة في `localStorage` الخاص بمتصفحك، **وليس في GitHub أو ملفات Frontend أو Backend**.
- عند الضغط على توليد البرومبت يُرسل المفتاح إلى Backend داخل JSON لهذا الطلب فقط؛ يستخدمه Backend للاتصال بخدمة NVIDIA ولا يخزّنه أو يسجّله ضمن كود التطبيق.
- إذا تركت الخانة فارغة، يستخدم Backend **Fallback Generator**. وإذا لم يرد الخادم، تعمل نسخة Fallback داخل المتصفح.
- لحذف المفتاح، اضغط **حذف** بجوار الخانة، ولا تستخدم مفتاحك على جهاز عام أو مشترك.
- تخزين `localStorage` قابل للقراءة بواسطة النصوص البرمجية التي تعمل على أصل الصفحة، وليس مخزنًا مشفرًا؛ احمِ متصفحك وحساب GitHub. أي طلب باستخدام NVIDIA يستلزم اتصالًا خارجيًا بخدمة NVIDIA، لكن التطبيق نفسه لا يصبح عامًا لهذا السبب.

**لا ترفع أي ملف `.env` حقيقي، ولا تضع مفاتيح في GitHub أو ملفات المشروع أو السجلات أو الصور.** ملفات `.env.example` الموجودة بالقالب لا تحتوي أسرارًا.

## التحقق من التشغيل

بعد تشغيل الواجهة والخادم:

- افتح الصفحة، اختر صورة مرجعية وغيّر الخيارات العربية واتجاه RTL.
- اترك خانة المفتاح فارغة للتأكد من أن برومبت Fallback يُنشأ بالإنجليزية ويبدأ بـ `ChatGPT, using the reference image I uploaded, generate an image of the exact same person`.
- اختبر زر النسخ. لا يرسل التطبيق صورتك المرجعية إلى NVIDIA أو Backend.
- إذا رغبت في التأكد من جودة ملفات المشروع، نفّذ اختياريًا:

```bash
npm run typecheck
npm run build
npm test
```

## القواعد الثابتة

- الهوية كما في الصورة المرجعية بالضبط: وجه ولون بشرة ونسب جسم دون تجميل أو تعديل، وتسريحة الشعر ضمن كثافته وخط نموه الأصلي.
- السيارة **Range Rover Sport 2022** أبيض لؤلؤي، باقة رياضية وجنوط سوداء، بداخلها جلد ومقاعد وطبلون ومقود بيج وسقف بانورامي، وتبقى **متوقفة دائمًا**.
- التصوير سيلفي خام بالكاميرا الأمامية، ومنظور الذراع والإضاءة والظلال وتوزيع الوزن واقعي.
- ممنوع الجلد الشمعي والبلاستيكي والخزفي والفلاتر وCGI والمبالغة في HDR؛ تفاصيل البشرة والملابس والخلفية طبيعية.
- كل الأماكن سعودية يومية بدون معالم مشهورة والخلفية حية وليست فارغة.
- واجهة المستخدم عربية فقط RTL، والبرومبت النهائي **بالإنجليزية فقط** وموجّه إلى ChatGPT ويبدأ حرفيًا بـ:

```text
ChatGPT, using the reference image I uploaded, generate an image of the exact same person
```

## ممنوع النشر العام

لا تضف خدمات استضافة عامة، ولا تغيّر المستودع إلى Public، ولا تفعّل GitHub Pages، ولا تغيّر منافذ Codespaces إلى Public. هذا الدليل للتشغيل الخاص فقط. المستودع الخاص وحده لا يحمي منفذًا جعلته عامًا يدويًا؛ افحص **Ports** في كل جلسة Codespaces.
