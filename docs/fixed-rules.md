# القواعد الثابتة غير القابلة للتفاوض

هذا المستند هو مرجع كتابة واختبار أي برومبت. لا يسمح خيار أو توسعة إبداعية بتغيير هذه الثوابت.

## ثوابت لا تتغير

- **الهوية:** الصورة المرجعية هي المصدر الوحيد للشخص؛ لا تغيير للوجه أو لون البشرة أو الشعر؛ يسمح فقط بتكييف نسب الجسم إلى طول 195 سم ووزن 88 كجم وبنية Lean Athletic دون تغيير الوجه، ولا تجميل أو تبييض أو تنعيم. الشعر يحتفظ بخط نموه وكثافته وطوله الأصلي، وتتغير جهة التسريح فقط بما تسمح به الصورة.
- **السيارة:** Range Rover Sport 2022 باللون الأبيض اللؤلؤي، باقة رياضية وجنوط سوداء؛ الداخلية جلد بيج فاتح للمقاعد والأبواب ومسند الذراع، خشب داكن لامع وكروم وPiano Black، مقود أسود ثلاثي الأذرع وشاشة طولية وتحكم بالمناخ وسقف بانورامي. السيارة متوقفة دائمًا.
- **التصوير:** سيلفي خام من الكاميرا الأمامية بيد الشخص، منظور ومسافة ذراع حقيقيان، ميلان وتكوين غير مثالي قليلًا، وضوضاء مستشعر وإضاءة وظلال منطقية.
- **الواقعية:** ممنوع الجلد الشمعي أو البلاستيكي أو الخزفي، وفلاتر التجميل وCGI والعرض ثلاثي الأبعاد وHDR المبالغ فيه. تظهر مسام الجلد وملمس القماش وغبار السيارة بصورة طبيعية بلا إضافة عيوب مختلقة.
- **المكان:** مشاهد سعودية يومية عامة دون أسماء معالم أو مولات أو أبراج مشهورة؛ خلفية غير فارغة مع نشاط بشري ومروري منطقي، والسيارة الأساسية لا تتحرك.
- **اللغة:** واجهة المستخدم واختياراتها بالعربية فقط واتجاهها RTL؛ الناتج برومبت واحد بالإنجليزية فقط موجّه إلى ChatGPT ويبدأ حرفيًا بـ:

```text
ChatGPT, using the reference image I uploaded, generate an image of the exact same person
```

تُستكمل الجملة بتفاصيل المشهد، ولا يضاف نص عربي أو شرح أو Negative Prompt منفصل داخل الناتج.

## قاعدة تكوين الصورة والجسم والمقصورة

- الطول **195 سم**، الوزن **88 كجم** والبنية **Lean Athletic** ثوابت لا يحق للاختيارات أو NVIDIA تغييرها، مع تثبيت هوية الوجه والشعر والبشرة من المرجع.
- الشخص من الصورة المرجعية هو **الموضوع الرئيسي الوحيد**. لا تُبعَد الكاميرا أو تُوسّع زاويتها أو يُصغَّر الشخص لاستعراض السيارة أو الجسم الكامل أو المقصورة. لا تظهر إلا الأجزاء التي تسمح بها زاوية السيلفي الطبيعية.
- مواصفات المقصورة ثابتة عند ظهورها: جلد بيج فاتح ومقاعد بخياطة طولية ودعامات جانبية ومسند يد بيج، أبواب بيج بقطاعات علوية أغمق، خشب داكن لامع وكروم وPiano Black، مقود أسود ثلاثي الأذرع، لوحة عدادات رقمية، شاشة ترفيه طولية، تحكم بالمناخ أسفلها وسقف بانورامي. لا تفرض على الصورة إظهار كل هذه الأجزاء.
- يمنع الوصف السابق للمقود البيج نهائيًا؛ المقود الأسود هو المرجع النهائي. تُرفض أو تُستبعد أي توسعة إبداعية تتعارض مع هذه الثوابت.
- النصوص الإنجليزية الحرفية المطلوبة محفوظة في `backend/src/rules/body.rules.ts` و`backend/src/rules/composition.rules.ts` و`backend/src/rules/cabin.rules.ts`، ويطابقها مولّد المتصفح المحلي في `frontend/src/data/fixedRules.ts`.

## آلية ضبط التعارض

- إذا طلبت تسريحة طول شعر غير موجود بالمرجع، تُعدّل إلى أقرب حركة واقعية ضمن الشعر الأصلي دون اختراع كثافة.
- إذا تعارضت الوقفة والزاوية مع وصول اليد للهاتف، يُصحّح منظور السيلفي والذراع مع المحافظة على نية اللقطة.
- إذا تضاربت الإضاءة المختارة مع وقت المكان، يجب جعل المشهد متسقًا بمصدر ضوء موجود، لا اختراع إضاءة خفية.
- إذا تضمّن خيار منطقة قد تكون خالية، تُضاف تفاصيل بشرية/مرورية معقولة بلا معالم مسماة.
- إذا وُصفت حركة الشخص قرب السيارة، فالسيارة ذاتها تبقى متوقفة حتى لو مرت مركبات أخرى بالخلفية.

## اختبار الامتثال

يجب أن يبدأ الناتج حرفيًا بالمقدمة الثابتة، وأن يكون إنجليزيًا، ويذكر السيارة البيضاء والداخلية البيج والوقوف والسيلفي الخام ورفض الجلد الشمعي والبلاستيكي والتصوير الصناعي. يحمي Backend هذه القواعد ببناء ثابت وتحقق نصي، ويسقط إلى fallback عند رفض ناتج النموذج؛ هذا لا يعني قدرة على ضمان الشكل الذي ينتجه نموذج الصور لاحقًا.

## مسار العمل

```text
Frontend (React + TypeScript + Vite, Arabic RTL)
  → JSON: { selections, variation }
  → POST /api/prompt
Backend (Node.js + TypeScript + Express)
  → Validation → Rule Builder → Creative Expander
  → NVIDIA API (deepseek-ai/deepseek-v4.1-flash)
  → Prompt Validator → English ChatGPT prompt
  ↳ NVIDIA missing/unavailable/invalid → Backend Fallback Generator
  ↳ Backend unreachable → Frontend local fallback
```

عنوان خدمة NVIDIA: `https://integrate.api.nvidia.com/v1/chat/completions`. لا يرسل Frontend الصورة المرجعية إلى Backend ولا إلى NVIDIA؛ يُنسخ البرومبت وتُرفع الصورة في ChatGPT بشكل منفصل.

## التشغيل على الجهاز

المتطلبات: Node.js مطابق للشرط في `package.json` (مثل Node.js 22.12+)، وnpm 10+.

من جذر المستودع نفّذ:

```bash
npm install
```

انسخ ملف `backend/.env.example` إلى `backend/.env` محليًا. داخل **`backend/.env` فقط** ضع مفتاحك الخاص في `NVIDIA_API_KEY` إن أردت استخدام NVIDIA. تركه فارغًا يشغّل المولّد الاحتياطي بدون الاتصال بـNVIDIA. لا تضع المفتاح في Frontend أو متغيرات `VITE_*` أو أي ملف مرفوع إلى GitHub.

افتح نافذتي طرفية من جذر المشروع:

```bash
npm run dev:backend
```

```bash
npm run dev:frontend
```

الواجهة عادة على `http://localhost:5173`، والخادم على `http://localhost:3001`، والفحص الصحي `http://localhost:3001/health`. يوجّه Vite المسار `/api` إلى Backend تلقائيًا أثناء التطوير.

للتحقق قبل النشر:

```bash
npm run typecheck
npm run build
npm test
```

## ملاحظات النشر

ابنِ الحزمتين من جذر المشروع بـ `npm install` ثم `npm run build`. انشر `frontend/dist` كملفات ثابتة، وشغّل Backend ببيئة Node.js (مثل `npm run start` بعد البناء) وتحقق من صحة `/health`.

هناك طريقتان للربط:

1. **نطاق واحد:** وجّه طلبات `/api/*` إلى خادم Backend، وقدّم باقي الطلبات من `frontend/dist`؛ بهذا يبقى `VITE_API_BASE_URL` فارغًا.
2. **نطاقان مختلفان:** اضبط `VITE_API_BASE_URL` عند **بناء Frontend** إلى عنوان Backend الذي يصل إليه المتصفح (من دون `/api/prompt`). اضبط `CORS_ORIGINS` في Backend على أصل الواجهة الصحيح، واستخدم HTTPS.

خدمة Backend فقط تحمل `NVIDIA_API_KEY` في متغيرات بيئة الخادم أو `backend/.env` المحلي غير المتتبّع؛ **لا تنشر ملف .env الحقيقي ولا تكشف المفتاح في المتصفح أو GitHub**. `.env.example` قالب بلا أسرار. لا يفترض المشروع أن Vite proxy التطويري يعمل في الإنتاج؛ يلزم Proxy إنتاجي أو عنوان Backend كما سبق.
