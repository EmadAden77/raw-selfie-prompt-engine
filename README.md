# محرك برومبت سيلفي واقعي
# Raw Selfie Prompt Engine

تطبيق ويب لإنشاء برومبتات إنجليزية دقيقة وموجهة إلى ChatGPT لتوليد صور سيلفي واقعية اعتمادًا على الصورة المرجعية للمستخدم واختياراته.

**التطبيق يولّد البرومبت فقط، ولا يولّد الصور.**

**الاستخدام المقصود شخصي وخاص فقط:** تشغيل محلي أو في Codespaces بمنافذ خاصة، دون نشر عام.

## فكرة المشروع

1. يرفع المستخدم صورته المرجعية الخاصة به.
2. يختار تفاصيل الصورة من واجهة عربية بالكامل.
3. يحوّل التطبيق الاختيارات إلى بيانات منظمة.
4. يعالج المحرك الاختيارات مع القواعد الثابتة.
5. يستخدم المحرك NVIDIA API لتحرير البرومبت الإنجليزي فقط بعد أن يثبت Rule Builder جميع الحقائق.
6. يتحقق من البرومبت النهائي.
7. يعرض برومبتًا إنجليزيًا جاهزًا للنسخ والاستخدام في ChatGPT.

عند فشل الاتصال بخدمة NVIDIA، يستخدم التطبيق مولّدًا محليًا قائمًا على القواعد دون تعطيل عملية إنشاء البرومبت.

## قواعد اللغة

- واجهة التطبيق عربية بالكامل.
- اتجاه الواجهة من اليمين إلى اليسار (RTL).
- جميع العناوين والأزرار والخيارات باللغة العربية.
- البرومبت النهائي باللغة الإنجليزية فقط.
- البرومبت النهائي موجّه إلى ChatGPT.
- لا تُضاف تعليمات عربية داخل البرومبت النهائي.

يبدأ كل برومبت بالنص التالي:

```text
ChatGPT, using the reference image I uploaded, generate an image of the exact same person...
```

## القواعد الثابتة

### 1. الهوية المرجعية

- الحفاظ على هوية الشخص من الصورة المرجعية.
- عدم تغيير ملامح الوجه أو لون البشرة أو الشعر؛ يسمح فقط بضبط نسب الجسم لتوافق القامة والوزن الثابتين دون تعديل الوجه.
- عدم تطبيق التجميل أو تنعيم البشرة أو التبييض.
- الحفاظ على نسيج البشرة ومسامها الطبيعية.
- الحفاظ على كثافة الشعر وسماكته وخط نموه الأصلي.
- السماح بتغيير اتجاه التسريحة دون تغيير خصائص الشعر الأصلية.

### 2. السيارة الثابتة

**السيارة:** Range Rover Sport 2022

المواصفات الخارجية:

- اللون الأبيض اللؤلؤي.
- الباقة الرياضية.
- جنوط سوداء.
- شبك أمامي أسود.
- مصابيح LED أمامية.

المواصفات الداخلية:

- جلد بيج.
- مقاعد بيج.
- مقصورة جلد بيج فاتح، مع خشب داكن لامع وكروم وPiano Black وشاشة ترفيه عمودية وتحكم مناخي أسفلها.
- مقود أسود مكسو بالجلد بثلاثة أذرع وأزرار متعددة الوظائف، مع لوحة عدادات رقمية.
- ألواح أبواب بيج.
- سقف بانورامي.

لا يسمح المحرك بتغيير لون السيارة أو مواصفات الداخلية الثابتة.

### المواصفات الجسدية والتكوين الثابتان

- طول الشخص المستهدف **195 سم** ووزنه **88 كجم** وبنية **Lean Athletic** طبيعية؛ تناسب الأطراف والخصر والأكتاف وعضلات خفيفة بلا تضخيم أو نحافة مفرطة.
- لا تُغيّر هوية الوجه أو البشرة أو الشعر لتكييف الجسم، ولا تُطوّل الأطراف أو تغيّر منظور السيلفي بصورة غير واقعية.
- الشخص المرجعي هو **الموضوع الرئيسي الوحيد**. لا يُوسّع الكادر لإظهار الجسم الكامل أو السيارة أو المقصورة أو المكان؛ تُذكر التفاصيل الداخلية كاملةً كقواعد هوية عند إمكان ظهور المقصورة، لكن لا تظهر بصريًا إلا الأجزاء الواقعة ضمن زاوية السيلفي الطبيعية.
- المقصورة لا تتبدّل: الجلد البيج الفاتح للمقاعد والأبواب ومسند اليد، المقود **أسود**، والخشب الداكن اللامع والكروم وPiano Black والتوزيع الداخلي كما في مواصفات القواعد.

### 3. السيلفي الخام

- تصوير بالكاميرا الأمامية للهاتف.
- منظور سيلفي حقيقي بيد الشخص نفسه.
- تشوه عدسة طفيف وطبيعي.
- ذراع وظلال ومنظور متوافق مع وضعية التصوير.
- تأطير عفوي وغير مثالي قليلًا.
- ضوضاء مستشعر الهاتف ونطاق ديناميكي واقعي.
- عدم استخدام إضاءة استوديو أو مظهر كاميرا احترافية.

### 4. منع المظهر الصناعي

المظهر المطلوب واقعي وطبيعي.

يمنع المحرك:

- Wax skin
- Plastic skin
- Porcelain skin
- Airbrushed skin
- Beauty filters
- CGI appearance
- 3D-rendered appearance
- Unrealistic HDR
- Artificially glossy surfaces

مع الحفاظ على ملمس البشرة الحقيقي وتجاعيد الملابس الطبيعية والغبار والانعكاسات الواقعية عند ملاءمتها للمشهد.

### 5. الأماكن والسيارة

- جميع المواقع بيئات سعودية يومية عامة.
- عدم استخدام أسماء معالم أو مولات أو أبراج مشهورة.
- السيارة متوقفة دائمًا.
- لا تتضمن البرومبتات قيادة السيارة أثناء الحركة.
- الخلفيات حية وليست فارغة.
- إضافة عناصر واقعية متوافقة مع الموقع والوقت والإضاءة.

### 6. الفيزياء والهندسة

- توافق وضعية الجسم مع زاوية الكاميرا.
- صحة مواضع اليدين والذراعين والمفاصل.
- اتساق اتجاه الضوء والظلال والانعكاسات.
- توافق الملابس مع الجاذبية والحركة.
- احترام المسافات والمنظور.
- تجنب التعارض بين الزاوية والوضعية والمكان.

## محرك إنشاء البرومبت

يتكون المحرك من طبقتين أساسيتين.

### Rule Builder

مسؤول عن:

- استقبال الاختيارات المنظمة.
- إضافة القواعد الثابتة.
- تثبيت الهوية المرجعية.
- تثبيت مواصفات السيارة.
- تثبيت الطول 195 سم والوزن 88 كجم والبنية الرياضية الخفيفة وقاعدة أولوية الشخص داخل الكادر.
- ضمان واقعية السيلفي.
- منع تعارضات الخيارات.
- إنشاء البرومبت الأساسي بالإنجليزية.

### Creative Expander

مسؤول عن:

- إضافة تفاصيل واقعية مناسبة للمشهد.
- تحسين وصف البيئة والخلفية.
- إضافة الانعكاسات والظلال الطبيعية.
- وصف حركة الشعر والملابس.
- إضافة تفاصيل العفوية والفوضى الواقعية.

لا توجد طبقة توسع إبداعي في مسار NVIDIA الحالي؛ يعمل NVIDIA محررًا لغويًا فقط، ويُرفض أي تغيير أو إضافة للمعلومات.

### Prompt Validator

يتحقق من:

- بداية البرومبت الإلزامية.
- اللغة الإنجليزية.
- وجود القواعد الثابتة.
- الحفاظ على مواصفات السيارة، والمقود الأسود والمواد الداخلية دون تعارض.
- التأكد من الطول 195 سم والوزن 88 كجم وLean Athletic وأن الشخص وحده هو الموضوع الرئيسي.
- عدم وصف السيارة أثناء القيادة.
- عدم وجود معالم مشهورة.
- الاتساق بين تفاصيل المشهد.

### Fallback Generator

إذا تعذّر استخدام NVIDIA API، يُنشئ البرومبت اعتمادًا على Rule Builder دون الحاجة إلى خدمة الذكاء الاصطناعي الخارجية.

## NVIDIA API — تحرير فقط بدرجة حرارة 0.25

المحرّك يبني النص الكامل قبل الاتصال بـ NVIDIA؛ ويقبل فقط التنقيح التحريري المتحقق من ثبات كل جملة. تفاصيل التنفيذ في [دليل محرر NVIDIA v10](docs/nvidia-editor-only-v10.md).

إعدادات الاتصال المعتمدة:

```text
Base URL:
https://integrate.api.nvidia.com/v1/chat/completions

Model:
deepseek-ai/deepseek-v4.1-flash
```

**حماية المفتاح في الإصدار v9:**

- مفتاح NVIDIA لا يدخل إلى الواجهة ولا يُخزّن في المتصفح. الخادم يقرأ `NVIDIA_API_KEY` من `backend/.env` محليًا أو من إعدادات البيئة السرية لخادم الاستضافة فقط.
- إذا لم تُضبط قيمة صالحة في الخادم، يعمل المولد المحلي دون انقطاع. إذا تعذّر الاتصال بالخادم يعمل إصدار القواعد المضمّن في المتصفح.
- تم حذف الحقل القديم الذي كان يحفظ المفتاح في `localStorage`، مع مسح القيمة المتبقية عند فتح النسخة الجديدة.
- صورة المرجع لا تُرسل إلى Backend أو NVIDIA؛ التوليد الفعلي للصورة يتم في ChatGPT.

## التشغيل محليًا أو على Codespaces

1. نفّذ `npm install` داخل جذر المشروع.
2. انسخ `backend/.env.example` إلى `backend/.env` محليًا، وضع `NVIDIA_API_KEY` هناك فقط إذا أردت الاتصال بـ NVIDIA.
3. شغّل `npm run dev:backend` و`npm run dev:frontend` ثم افتح `http://localhost:5173`.
4. في Codespaces، أبق المنفذ 5173 خاصًا. لا تشارك المفاتيح في ملفات المشروع أو Issues أو مخرجات التشغيل.

الواجهة متاحة علنًا على GitHub Pages وخادم API يعمل على Vercel. **لا تفعّل مفتاحًا مدفوعًا على نقطة API عامة دون مصادقة وحدّ استهلاك مركزي**؛ CORS والحدّ الذاكري للطلبات لا يمنعان استهلاك المفتاح بواسطة أطراف أخرى. انظر [دليل النشر والأمان](docs/deployment.md).

## خصوصية الصورة المرجعية

- يستخدم التطبيق الصورة المرجعية الخاصة بالمستخدم فقط.
- الصورة المرجعية مخصصة للاستخدام مع البرومبت في ChatGPT.
- لا يحتاج محرك إنشاء النص إلى إرسال الصورة المرجعية إلى NVIDIA.
- لا تُضمّن بيانات الصورة في طلب توليد البرومبت النصي.
- لا تُخزن الصور المرجعية على الخادم ضمن التصميم الأساسي.
- المستخدم مسؤول عن رفع صورته إلى ChatGPT عند استخدام البرومبت.

## أمان التطبيق

- تخزين مفتاح NVIDIA في بيئة الخادم السرية فقط، مع إزالة أي مفتاح قديم من تخزين المتصفح.
- التحقق من بيانات الطلبات.
- تحديد معدلات الطلبات.
- معالجة أخطاء الخدمات الخارجية.
- عدم كشف بيانات البيئة السرية.
- توفير توليد بديل عند فشل NVIDIA API.

## حالة المشروع

المشروع يعمل محليًا وفي Codespaces، وله أيضًا واجهة عامة على GitHub Pages وخادم API على Vercel. تحتاج حماية الاستدعاءات المدفوعة إلى مصادقة مستقلة إذا تم تفعيل مفتاح NVIDIA في بيئة الإنتاج.
