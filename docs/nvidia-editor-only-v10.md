# محرك v10 — Rule Builder هو مصدر الفيزياء الوحيد

## المسار النهائي

1. واجهة التطبيق (عربية RTL) ترسل معرّفات الاختيارات فقط. لا تُرسل الصورة المرجعية أو المفتاح.
2. `backend/src/data/option-mappings.ts` يفسّر الخيارات؛ `backend/src/engine/rule-builder.ts` يحدد الوقوف والإضاءة والخامات وهندسة المكان؛ `backend/src/engine/scene-geometry.ts` يصحح تعارضات زاوية السيلفي والوضعية.
3. `backend/src/engine/concise-prompt.ts` يجمع **البرومبت الإنجليزي النهائي** من القواعد الثابتة والاختيارات. لا يقبل إضافات فوتوغرافية أو فيزيائية من NVIDIA. `fallbackGenerator` يعيد هذا النص دون تنقيح.
4. `backend/src/services/nvidia.service.ts` يرسل البرومبت النهائي كاملًا إلى NVIDIA عند ضبط مفتاح صالح في متغير بيئة الخادم `NVIDIA_API_KEY`. درجة الحرارة `0.25`. لا يستخدم JSON للتخطيط.
5. `backend/src/engine/editor-validator.ts` يفحص النص المحرر مقابل نص Rule Builder. عند أي نقص، تغيير في الحقائق، معلومة مخترعة أو تعديل لغوي يصعب إثبات أمانه، يُرفض الرد ويُعاد نص Rule Builder **حرفيًا** (`source: local` و`reason: unsafe_output`).

## الضمانات المسبقة

- **الهوية:** نفس الشخص من المرجع دون تعديل الوجه والشعر والبشرة. القياسات المطلوبة في v10 هي **195 cm / 88 kg** وبنية رياضية نحيفة طبيعية.
- **السيارة:** Range Rover Sport 2022 أبيض لؤلؤي، باقة رياضية، جنوط سوداء؛ المقصورة جلد بيج وطبلون بيج، مقود أسود، وسقف بانورامي وشاشتان Touch Pro Duo أصليتان. السيارة متوقفة دائمًا.
- **المكان:** مشاهد سعودية يومية غير معروفة الاسم. عند وجود رصيف في موضع وقوف مناسب، السيارة موازية له بعجلات مستقيمة على مسافة **20–30 cm** من رصيف خرساني بيج/رمادي ارتفاعه **15 cm**. عند الطريق الصحراوي لا يخترع المحرك رصيفًا، وفي المواقف يلتزم خطوط المواقف والأرضية المناسبة.
- **الإضاءة والفيزياء:** وقت التصوير، لون الإضاءة المقاس Kelvin، مصدر الضوء والظلال والجاذبية والدعم ومواضع الأيدي تحددها الخيارات والقواعد المحلية فقط.
- **الكادر:** 9:16 مع أولوية الوجه، ولا تظهر أي تفاصيل أخرى إلا إن سمحت زاوية السيلفي.

## لماذا المدقق متحفظ؟

لا يمكن لخوارزمية مقارنة نصوص أن تضمن تطابق المعنى الفيزيائي لأي إعادة صياغة إنجليزية حرة. لهذا يعمل المدقق بمقارنة **جميع الجمل الحاملة للحقائق وبالترتيب الداخلي لكلمات كل جملة**: يسمح بحروف كبيرة/صغيرة، حذف أو إضافة أدوات التعريف، وعلامات الترقيم والمسافات وترتيب الجمل الكاملة، ولا يقبل كلمات جديدة أو حذف كلمات واقعية.

هذا يعني أن بعض الاقتراحات البلاغية السليمة من NVIDIA قد تُرفض احتياطيًا. **الأولوية لعدم اختراع أي حقيقة**، وليس لإجبار المحرك على قبول تعديلات خارج نطاق الأمان.

## التشغيل والتحقق

```bash
npm run typecheck
npm run build
npm test
```

الاختبارات تشمل عدم تغيير 195/88، عدم إضافة مصادر ضوء أو تفاصيل مركبة، الرفض عند تحريف المقصورة أو الوقوف، وتطابق حقائق نسخة NVIDIA والـFallback. اختبارات الكود لا تثبت تطابق الصورة الناتجة بصريًا مع المرجع؛ ذلك يحتاج مقارنة مرئية منفصلة.

**لم يعد NVIDIA مخطط مشهد أو مولّد حقائق أو محرر فيزياء، ويظل التطبيق منتجًا للبرومبت فقط وليس للصور.**
