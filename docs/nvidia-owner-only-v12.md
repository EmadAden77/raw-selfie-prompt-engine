# NVIDIA Owner-Only Mode — v12

## الهدف

NVIDIA متاحة **لمالك التطبيق فقط**. الواجهة العربية RTL العامة تبقى قادرة على توليد البرومبت بواسطة Rule Builder v11؛ لا يُخصم رصيد NVIDIA عند استخدام الزوار.

## السرّان منفصلان

- `NVIDIA_API_KEY`: مفتاح NVIDIA الأصلي، يُحفظ في Vercel Production / Secret ولا يصل إلى المتصفح.
- `NVIDIA_OWNER_TOKEN`: رمز خاص جديد، عشوائي وطويل (32–256 حرفًا ASCII بلا مسافات)، يُحفظ في Vercel Production / Secret. يجب ألا يبدأ بـ `nvapi-` ولا ينبغي استخدام مفتاح NVIDIA نفسه.

**لا تُكتب قيمة أيٍّ من السرّين في ملفات GitHub، أو في محادثة، أو في رابط، أو في صورة شاشة.** أنشئ رمز المالك محليًا باستخدام مدير كلمات مرور أو أداة توليد رمز عشوائي موثوقة. احتفظ به لديك منفصلًا عن مفتاح NVIDIA.

## التشغيل

1. ضع السرّين في مشروع Vercel الصحيح `raw-selfie-nvidia-api` ببيئة Production.
2. أعد نشر خادم `main` بعد ضبط السرّين؛ مجرد الحفظ لا يحدّث النشر الجاري.
3. افتح واجهة GitHub Pages؛ اختر السيلفي كالمعتاد.
4. من قسم «NVIDIA الخاصة بصاحب التطبيق» أسفل الخيارات أدخل **رمز المالك فقط**.
5. عند إصدار البرومبت ترسل الواجهة رمز المالك في هيدر HTTPS باسم `X-Nvidia-Owner-Token`. لا ترسله في JSON أو البرومبت أو التخزين الدائم. يبقى في ذاكرة الصفحة حتى إغلاقها/إعادة تحميلها.
6. يقارن الخادم قيمة هاش الرمز بمساواة ثابتة الزمن. لا يستدعي NVIDIA دون تطابق السرّين والإذن. أي غياب أو خطأ أو ضعف في رمز المالك يعيد برومبت Rule Builder المحلي دون استهلاك NVIDIA.
7. بعد نجاح المصادقة تحتفظ NVIDIA بدورها **محررًا للإنجليزية فقط**؛ تتحقق الخوادم من جميع حقائق الفيزياء و195 cm / 88 kg، هوية الوجه، السيارة المتوقفة ومقصورتها الثابتة.

## الأمان والحدود

- CORS وتحديد عدد الطلبات لكل IP لا يكفيان وحدهما لحماية مفتاح مدفوع؛ مصادقة المالك هي حاجز التكاليف الفعلي هنا.
- لا تستخدم كلمة مرور قصيرة أو رقم PIN بسيط؛ يجب أن يكون الرمز عشوائيًا قويًا. لا يُخزن في `localStorage`، ولا `sessionStorage` ولا `VITE_*`.
- رمز الوصول شخصي: من يحصل عليه يمكنه استخدام حسابك. عند التسرب غيّره في Vercel وأعد النشر.
- رمز المالك **ليس** نظام حسابات أو جلسات أو سقف نفقات مركزي. للتحكم الصارم في الفاتورة، اضبط حدود الاستخدام والتكلفة لدى NVIDIA أيضًا.
- فشل NVIDIA أو عدم تفعيل المفتاح لا يعطل Rule Builder. لن تُرسل صورة المستخدم إلى NVIDIA، ولن ينشئ التطبيق صورًا.

## الاختبارات

```bash
npm run typecheck
npm run build
npm test
```

تشمل اختبارات المصادقة رفض جميع الطلبات دون الرمز الصحيح، عدم إرسال أي طلب إلى NVIDIA للزوار، قبول المالك فقط، نجاح CORS مع هيدر الدخول، وعدم ظهور أي مفتاح في المخرجات.
